# تطبيق خلفية مواقيت الصلاة (Live Wallpaper)

تطبيق أندرويد مبني على نفس منطق موقع RAHMO (Site2app)، بميزتين:

1. **Widget (ودجة الشاشة الرئيسية)** — الاستخدام الأساسي المطلوب: صندوق يوضع بين أيقونات الشاشة الرئيسية، يعرض الأوقات الخمسة على اليسار، وعدّاد تنازلي حي (يتحدث كل ثانية لحاله عبر Chronometer بدون استهلاك بطارية) + سهم ثابت لاتجاه القبلة بالنسبة للشمال الحقيقي على اليمين (رقم الدرجة مكتوب تحته، محاذاته يحتاج بوصلة عادية لتحديد الشمال لأن الودجة ما تقدر تقرأ حساس دوران الهاتف بشكل مستمر).
2. **Live Wallpaper (اختياري)** — نفس التصميم بس كخلفية حيّة تغطي كل الشاشة، مع بوصلة تدور لحظياً مع حركة الهاتف (تحتاج صلاحية النظام لهذا).

## الملفات الرئيسية (شرح تفصيلي)

### 1) `PrayerData.kt` — طبقة البيانات
مسؤول عن كل شي متعلق بالمواقيت والموقع، بدون أي رسم:
- **الموقع الجغرافي**: يحفظ ويقرأ آخر إحداثيات معروفة (`SharedPreferences`)، وإذا ما فيه موقع محفوظ يرجع لمدينة بورصة كافتراضي (تماماً متل `app.js` بالموقع الأصلي).
- **`reverseGeocode()`**: يستخدم نفس خدمة BigDataCloud اللي يستخدمها الموقع لتحويل الإحداثيات لاسم مدينة بالعربي.
- **`refreshBlocking()` / `refreshAsync()`**: يجيب مواقيت اليوم *وأيضاً فجر الغد* (نحتاجه لو كانت العشاء آخر صلاة انتهت، عشان العدّاد يحسب صح لين فجر اليوم التالي) من نفس API الأصلي (`aladhan.com`, method=13 وهو طريقة ديانت تركيا المستخدمة بالموقع).
- **`next()`**: يحسب أقرب صلاة قادمة بالنسبة للوقت الحالي.
- فيه تخزين مؤقت (cache) بحيث ما يسوي طلب إنترنت كل ثانية — يتحقق فقط لو تغيّر اليوم أو الموقع.

### 2) `PrayerWallpaperService.kt` — الخلفية الحيّة نفسها
هذا هو "المحرك" اللي يرسم كل شي على الشاشة كل فريم:
- **حساب اتجاه القبلة**: معادلة فلكية (`qiblaBearing`) تحسب الزاوية من موقعك إلى إحداثيات الكعبة (21.422487, 39.826206) مباشرة — نفس الطريقة المستخدمة بكل تطبيقات القبلة.
- **قراءة حساس الدوران** (`Sensor.TYPE_ROTATION_VECTOR`): يجيب اتجاه الهاتف الحقيقي بالنسبة للشمال المغناطيسي، ثم يصحّحه بـ "الانحراف المغناطيسي" (`GeomagneticField`) عشان يصير بالنسبة للشمال الحقيقي (الجغرافي) مو المغناطيسي — هذا يخلي البوصلة دقيقة.
- **الرسم (`render`)**:
  - يرسم القائمة اليسرى (٥ صفوف)، ويبرز الصلاة القادمة بخلفية ذهبية فاتحة.
  - يرسم العمود الأيمن: اسم الصلاة القادمة + عدّاد HH:MM:SS + وقتها بالضبط.
  - يرسم دائرة البوصلة: تدور مع حركة الهاتف، وسهم القبلة يصير لونه أخضر لما تكون بالاتجاه الصحيح بالضبط (دقة أقل من ٤ درجات).
- يعيد الرسم ~15 مرة بالثانية إذا فيه حساس دوران (حركة سلسة للبوصلة)، أو مرة كل ثانية إذا ما فيه حساس (بس للعدّاد).

### 3) `MainActivity.kt` — شاشة الإعدادات
هذي الشاشة اللي يفتحها المستخدم من قائمة التطبيقات (مو الخلفية نفسها):
- تطلب صلاحية الموقع (`ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`).
- تجيب آخر موقع معروف من نظام أندرويد، أو تنتظر تحديث لحظي لمدة ١٠ ثواني.
- تستدعي `PrayerData.reverseGeocode` و `refreshBlocking` بخيط منفصل (Thread) عشان ما تجمّد واجهة المستخدم.
- تعرض حالة واضحة بالعربي: جاري التحديد / جاري الجلب / تم / رفض الصلاحية / خدمة الموقع مغلقة / فشل.
- زر "تعيين كخلفية حيّة" يفتح شاشة أندرويد الرسمية لاختيار الخلفيات الحيّة، مع تحديد تطبيقنا مباشرة.
- مبنية بـ **Jetpack Compose** (طريقة أندرويد الحديثة لبناء الواجهات بالكود بدل XML).

### 4) `AndroidManifest.xml`
يعرّف:
- صلاحيتي الإنترنت والموقع.
- أن التطبيق يدعم الخلفيات الحيّة (`live_wallpaper` feature).
- شاشة `MainActivity` (نقطة الدخول).
- خدمة `PrayerWallpaperService` المرتبطة بنظام الخلفيات الحيّة بأندرويد (`BIND_WALLPAPER`).

### 5) `res/values/strings.xml`
كل النصوص العربية بمكان واحد (أسماء الصلوات، رسائل الحالة، عنوان التطبيق...) — تقدر تعدّل أي نص من هنا بدون لمس الكود.

### 6) `.github/workflows/build.yml`
ملف بناء تلقائي: كل ما ترفع كود على GitHub، يشغّل خادم مجاني يبني لك ملف APK جاهز للتثبيت، وتقدر تنزّله من تبويب Actions — هذا اللي يخليك تبني التطبيق بدون كمبيوتر أو Android Studio.
